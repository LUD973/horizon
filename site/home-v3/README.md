# French Class Prestige — Accueil v3

Fichiers publics de la page d’accueil (version mobile et version ordinateur),
chargés par la page WordPress via jsDelivr.

- `fcp-home.js` : la page (mobile < 1024 px, ordinateur ≥ 1024 px) et l’envoi des demandes
  vers l’API `/wp-json/fcp/v1/enquiries` (aucun paiement en ligne).
- `img/` : visuels provisoires. Pour remplacer une photo, déposer un fichier du même nom
  (même cadrage conseillé), puis mettre à jour la référence de version dans WordPress.
